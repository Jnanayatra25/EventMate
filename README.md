# EventMate

EventMate adalah aplikasi Android untuk membantu pengguna menemukan, mengikuti, dan mengelola berbagai event berdasarkan kategori, waktu, dan lokasi.

## Features

* Login & Register
* Explore Event
* Search & Filter Event
* Event Detail
* Create, Edit, Delete Event
* Event Registration
* Saved Event
* Event Map
* Location-based Check-in
* Event Documentation
* Review & Rating
* User Profile

## Core Features

**CRUD**
Digunakan untuk mengelola data event, termasuk membuat, melihat, mengubah, dan menghapus event.

**Camera**
Digunakan untuk mengambil foto dokumentasi event.

**Location**
Digunakan untuk menampilkan lokasi event, mencari event di sekitar pengguna, dan melakukan check-in.
